## RishDesk 1.1.0 — first public release

RishDesk is a free, open-source, landscape-first glass launcher for Android, made by Rish Innovations.

### Highlights
- Desktop-style home grid with drag-and-drop shortcuts, folders and resizable widgets
- Searchable app drawer with favorites and hidden apps
- Customisable dock, USB OTG tile and keyboard shortcuts
- Frosted-glass interface with accent colours
- Wallpaper editor: drag, pinch, set
- Works with gesture and 3-button navigation

### Install
Download `RishDesk-1.1.0.apk` below, open it, then press Home and choose **RishDesk** as your Home app. Verify the download with the `.sha256` file if you like.

Requires Android 8.0 or later. Tested mainly on a Realme C61 (Android 16): please [report issues](https://github.com/engineerharish05/Rish-Desk/issues/new/choose) from other devices.

### Known limits
Android does not let launchers force portrait-only apps into landscape, show a taskbar of running apps, or replace a file manager. See the [README](https://github.com/engineerharish05/Rish-Desk#limits-you-should-know-about).

Full list of changes: [CHANGELOG](https://github.com/engineerharish05/Rish-Desk/blob/main/CHANGELOG.md). Privacy: no data collected, no internet permission.

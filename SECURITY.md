# Security Policy

## Supported versions

Security fixes should target the current development version on `main`. Preview builds are provided for testing and may not be suitable as a primary launcher.

## Reporting a vulnerability

Please do not publish exploit details, credentials, private data, or an unpatched vulnerability in a public issue.

If GitHub's private vulnerability reporting or Security Advisories feature is available for this repository, use it to report the issue privately. Otherwise, contact the repository owner through their GitHub profile and request a private channel.

Include, where safe:

- A clear description of the issue and its impact.
- Steps to reproduce, with a minimal proof of concept if appropriate.
- Affected app version, Android version, and device model.
- Any practical mitigation you have identified.

Do not include passwords, signing keys, access tokens, or other secrets in the report.

## Scope and expectations

RishDesk is an Android launcher. Reports involving app-launch behavior, permissions, exposed data, unsafe intent handling, or build/release integrity are relevant. Response time is not guaranteed; please allow time for triage.

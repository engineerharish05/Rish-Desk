## Overview

RishDesk is an Android home-screen replacement built around a horizontal, desktop-like layout. It combines translucent glass surfaces, a dock, an app drawer, launcher settings, and selected system shortcuts.

> **Release status:** Preview build. The APK is generated by GitHub Actions. Test it on your own device before relying on it as your primary launcher.

## Download

**Latest release-preview build:**  
1. Open [GitHub Actions → Build RishDesk](https://github.com/engineerharish05/Rish-Deskdroid/actions/workflows/build.yml).
2. Open the latest successful workflow run.
3. Under **Artifacts**, download **RishDesk-release-preview**.
4. Extract the downloaded ZIP to get the APK.

The debug APK is also available as the **RishDesk-debug** artifact. The CI debug job runs unit tests before packaging the APK.

### Important signing note

The release-preview APK is signed with a temporary CI key so it can be installed and tested. That key is not retained between builds, so a later build may not install as an in-place update. You may need to uninstall the previous preview first. A stable public release with seamless updates requires a persistent release keystore stored securely as GitHub Actions secrets; never commit a keystore or passwords to this repository.

## Features

- **Landscape-only launcher experience** for the home screen and supported app launches.
- **Glass-inspired interface** with translucent surfaces and bright edges.
- **App drawer** with a 5 × 3 grid, horizontal paging, live case-insensitive search across app names and package IDs, persistent A–Z / Z–A / favorites-first sorting, favorites markers, and reversible app hiding.
- **Customizable dock** with app shortcuts and an app-drawer entry.
- **Launcher settings** for glass opacity, wallpaper, widgets, and keyboard shortcuts.
- **Persistent app organization** with favorites and hidden-app preferences stored locally.
- **Automated unit tests** for drawer search, hidden-app filtering, favorites ordering, and alphabetical sorting.
- **USB OTG shortcut** when a USB device is connected.
- **Keyboard shortcuts** that can be enabled in settings.
- **Android widgets** available through the system widget picker.

See [Design and behavior notes](#design-and-behavior-notes) for current implementation details and limitations.

## Install

1. Download and extract the release-preview artifact.
2. Open the APK on your Android device. If prompted, allow installation from that source.
3. Complete the installation and press the Android Home button.
4. Choose **RishDesk** as your Home app. Select **Always** if you want it as the default launcher.

To switch back, open Android **Settings → Apps → Default apps → Home app** and choose your previous launcher. The dock's **Exit** tile also opens Android's launcher picker.

**Compatibility:** Android 8.0 (API 26) or later. This project targets Android SDK 35.

## Build from source

### Requirements

- JDK 17
- Android SDK platform 35
- Gradle wrapper included in the repository

### Android Studio

1. Clone or download this repository.
2. Open the project root in Android Studio.
3. Allow Gradle sync to finish.
4. Run the `app` configuration on a device or emulator.

### Command line

```bash
chmod +x ./gradlew
./gradlew assembleDebug
./gradlew assembleRelease
```

The debug APK is written to `app/build/outputs/apk/debug/`. The release variant is written to `app/build/outputs/apk/release/` and is unsigned unless you configure signing locally.

### Build on GitHub

Every push to `main` that is not README-only triggers GitHub Actions. You can also start a build manually from the Actions tab. The workflow publishes debug and release-preview APK artifacts.

## Controls

| Area | Behavior |
| --- | --- |
| Home | Swipe up or tap the grid tile to open the app drawer. |
| App drawer | Search by app name or package ID, choose A–Z / Z–A / favorites-first sorting, swipe sideways for more pages, and long-press an app to favorite, hide, add to Home/dock, view app info, or uninstall. Use **Show hidden** to restore hidden apps. |
| Dock | Launch pinned apps, open settings, access OTG when available, or open the drawer. Long-press a dock app to remove it. |
| Glass settings handle | Opens a quick opacity slider. |
| Exit tile | Opens Android's Home app chooser. |
| Status bar | Swipe down from the top edge to reveal Android's system status and notification shade. |

### Keyboard shortcuts

Keyboard shortcuts are disabled by default and can be enabled in **Settings → Keyboard shortcuts**.

| Shortcut | Action |
| --- | --- |
| `Ctrl + D` | Open app drawer |
| `Ctrl + ,` | Open settings |
| `Ctrl + H` | Return home |
| `Ctrl + 1` to `Ctrl + 9` | Launch dock apps |
| `Esc` | Go back |

## Design and behavior notes

- The launcher interface is designed for landscape orientation.
- Wallpaper selection is stored by the launcher and does not change Android's system wallpaper.
- The OTG tile appears when a USB device is attached and opens the system file picker.
- Android supplies the system navigation controls in landscape.
- Translucent surfaces are used across the interface; wallpaper blur depends on Android version and device support.
- The widget picker displays widgets provided by installed apps. Android may request permission when a widget is added.
- Availability and behavior of app shortcuts can vary by Android version and device manufacturer.
